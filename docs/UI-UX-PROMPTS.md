## 1. 전체 디자인 시스템

### 🎯 v0.dev / Claude용 프롬프트

```
SOXL Safety Trading Web의 디자인 시스템을 개선해주세요.

현재 상태:
- 다크 테마 기반 금융 앱
- 주요 색상: Navy(#2563eb), Success(#10b981), Warning(#f59e0b), Danger(#ef4444)
- Tailwind CSS 사용

요구사항:
1. 전문적이고 신뢰감 있는 금융 앱 느낌
2. 데이터 가독성 최우선 (숫자, 차트, 상태)
3. 감정적 의사결정을 막는 차분한 색상
4. 위험/주의/안전 상태가 명확히 구분되는 색상 시스템
5. 눈의 피로를 최소화하는 다크 테마
6. 고대비 색상으로 가독성 확보

구체적으로:
- 그라데이션, 섀도우, 블러 효과를 활용한 현대적인 카드 디자인
- 상태별(BUY/SELL/STOP/HOLD) 독특한 비주얼 처리
- 숫자 강조를 위한 타이포그래피 시스템
- 마이크로 인터랙션 (hover, active, focus)
```

### 🎨 색상 팔레트 개선 프롬프트

```
금융 트레이딩 앱을 위한 감정 중립적인 색상 팔레트를 제안해주세요.

현재 색상:
- Primary: #2563eb (파랑)
- Success: #10b981 (초록)
- Warning: #f59e0b (노랑)
- Danger: #ef4444 (빨강)

개선 방향:
1. 공포/탐욕을 자극하지 않는 차분한 톤
2. 장시간 보기에 편안한 채도
3. 다크 모드에서 최적화
4. 색맹 사용자 고려
5. 상태별 색상 구분 명확성

출력 형식:
- Hex 코드
- RGB 값
- Tailwind CSS 클래스명
- 사용 케이스 설명
```

## 2. 메인 대시보드 개선

### 📊 프라이스 카드 리디자인

```
SOXL 가격 정보 카드를 리디자인해주세요.

현재 구성:
- 심볼명 (SOXL)
- 현재가 ($23.46)
- 등락률 (-8.0%)
- 등락금액 (-$2.04)
- 전일 종가 ($25.50)

개선 요구사항:
1. 실시간 느낌을 주는 펄스 애니메이션
2. 등락률에 따른 그라데이션 배경
3. 가격 변동 시 부드러운 카운터 애니메이션
4. 마이크로 차트 추가 (최근 5일 추세)
5. 고가/저가 범위 시각화
6. 거래량 표시 개선

React 컴포넌트로 구현해주세요 (TypeScript + Tailwind CSS).
```

### 🎯 액션 카드 인터랙티브 디자인

```
오늘의 행동 가이드 카드를 더 명확하고 인터랙티브하게 만들어주세요.

상태별 디자인:
1. BUY (매수)
   - 노란색 테마
   - 매수 금액/주수 강조
   - "지금 매수" 버튼 (시뮬레이션)
   
2. OVERBUY (과매수)
   - 주황색 테마
   - 긴급성 표현
   - 더 큰 금액 강조
   
3. SELL (매도)
   - 초록색 테마
   - 수익률 계산 표시
   - 매도 비율 슬라이더
   
4. STOP (중단)
   - 빨간색 테마
   - 중단 이유 명확히 표시
   - 경고 아이콘 애니메이션
   
5. NO_ACTION (대기)
   - 회색 테마
   - 차분한 분위기
   - 다음 조건까지 거리 표시

각 상태별 독특한 비주얼 아이덴티티를 가진 React 컴포넌트로 구현해주세요.
```

### 📈 예산 사용률 바 개선

```
예산 사용률 시각화를 더 직관적으로 만들어주세요.

현재: 단순 프로그레스 바

개선안:
1. 세그먼트 바 (0-30% 안전, 30-50% 주의, 50%+ 위험)
2. 각 구간별 색상 전환 애니메이션
3. 마일스톤 마커 (25%, 50%, 75%)
4. 남은 예산 도넛 차트 대안
5. 사용 내역 미니 타임라인
6. "안전 구간" 강조 표시

2-3가지 디자인 옵션을 제시해주세요.
```

4. 호버 시 상세 설명 툴팁

2. **2단계**: 개별 컴포넌트 개선
3. **3단계**: 애니메이션 추가
4. **4단계**: 모바일 최적화
5. **5단계**: 접근성 검증

### 반복 개선 프로세스

```
프롬프트 입력 → 결과 확인 → 피드백 → 재생성
```

각 컴포넌트를 3-5회 반복 개선하면 최적의 결과를 얻을 수 있습니다.
